Projetos Destacados

📈 Projeto 1: Análise e Otimização de Inventário (Power BI)

  • Engenharia de Dados (ETL): Desenvolvi um ETL complexo no Power Query (M) para migrar o modelo de uma tabela centralizada, monolítica, para um Star Schema otimizado, garantindo performance e escalabilidade.
  • Otimização de Performance: A otimização do modelo resultou em uma redução de 98,8% no tempo de carregamento dos visuais, comprovado via Analisador de Desempenho.
  • Business Intelligence (DAX): Criei KPIs avançados em DAX para medir o impacto financeiro das perdas, a acuracidade do inventário e a performance por filial.

Tecnologias: Power BI, Power Query (M), DAX, Modelagem Star Schema, Otimização de Performance
